# Dashboard de Análise de VendasDescrição 📊
* Este projeto consiste em um dashboard interativo desenvolvido no Power BI para análise de desempenho comercial. 
* O objetivo é transformar dados brutos de vendas em insights estratégicos, permitindo o acompanhamento de métricas fundamentais para a tomada de decisão.
* O arquivo disponibilizado é um template (.pbit), o que garante que a estrutura de dados e o layout visual sejam preservados sem incluir dados sensíveis diretamente no arquivo.
* Base de dados retirada do Power BI .
* Tema Personalizado: Utilização do tema Accessible City Park para garantir acessibilidade e contraste visual.

* 🛠️ Tecnologias Utilizadas:
* Power BI (Modelagem e Visualização)
* Power Query (ETL e Tratamento de Dados)
